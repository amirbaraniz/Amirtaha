# Amirbarani — امیربارانی · نسخه ۳

وب‌سایت رزومه فارسی و استاتیک امیرطاها بارانی‌زاده. تنها HTML، CSS و JavaScript خالص؛ بدون React، Node.js اجرایی یا دیتابیس.

## راه‌اندازی ویندوز

1. پروژه را از ZIP استخراج و همه فایل‌ها را در ریشه `my-web` قرار دهید.
2. سه فایل **واقعی** فونت Vazir موجود روی رایانه خود را در `assets/fonts/` کپی کنید:
   - `Vazir.woff`
   - `Vazir-Light.woff`
   - `Vazir-Bold.woff`
3. عکس خود را در `assets/images/prfile.jpg` جایگزین عکس داخل بسته کنید.
4. در CMD از ریشه سایت اجرا کنید: `py -m http.server 8000` و `http://localhost:8000` را باز کنید.

> توجه: فایل‌های واقعی Vazir در گفت‌وگو بارگذاری نشده‌اند و داخل این بسته نیستند. فونت Noto Sans Arabic به عنوان fallback قانونی داخل بسته قرار دارد. عکس موجود در `prfile.jpg` نیز یک تصویر جایگزین است؛ پیش از انتشار تصویر واقعی خود را قرار دهید.

## انتشار روی GitHub Pages

- محتوای ریشه ZIP را در شاخه `main` ریپازیتوری آپلود کنید.
- در GitHub: `Settings → Pages → Build and deployment → GitHub Actions`.
- فایل `.github/workflows/deploy-pages.yml` همراه پروژه موجود است.
- URLها و canonical و Sitemap در workflow برای مسیر اصلی یا زیرمسیر repo اصلاح می‌شوند.
- فایل `_headers` در GitHub Pages اعمال نمی‌شود؛ برای Cloudflare Pages مناسب است.

## نکته مهم درباره فرم

این سایت **بک‌اند یا سرویس ارسال ایمیل ندارد**. فرم پیام را با `mailto:` در برنامه ایمیل دستگاه آماده می‌کند؛ سایت نمی‌تواند موفقیت ارسال قطعی را تشخیص دهد. پیام سبز فقط می‌گوید پیام آماده شده و ادامه ارسال باید در برنامه ایمیل تأیید شود؛ عمداً تأیید کاذب «ایمیل ارسال شد» نمایش داده نمی‌شود. برای ارسال داخل خود سایت باید سرویس ارسال واقعی متصل شود.

## سرعت و امنیت

- HTML آماده، CSS/JS محلی و کم‌حجم، عکس پروفایل با اولویت بالا و تصاویر پایین صفحه با بارگذاری تنبل.
- فایل‌های آیکون CDN از نسخه ثابت Lucide/Devicon استفاده می‌کنند و fallback محلی دارند.
- هیچ تصویر تزئینی یا آیکونی مانع خواندن متن اصلی نمی‌شود.
- انیمیشن‌های Reveal و Hover بر پایه opacity/transform هستند و `prefers-reduced-motion` را رعایت می‌کنند.
- Service Worker نسخه‌دار است و برای جلوگیری از کش نسخه‌های قبلی، کش‌های مربوطه را هنگام فعال‌سازی پاک می‌کند.
- سیاست CSP در `_headers` برای میزبان‌هایی که آن را پشتیبانی می‌کنند فراهم شده است.
- ادعای تضمین سرعت یا بدون باگ بودن روی همه دستگاه‌ها وجود ندارد؛ آزمایش قبل از انتشار ضروری است.
