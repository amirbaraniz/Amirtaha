AMIRBARANI / NOTES

RTL واقعی، تایپوگرافی فارسی، کیبورد و اندازه مناسب عناصر لمسی. در ادامه چند اصل برای بهتر شدن تجربه کاربر را مرور می‌کنیم.

جهت صفحه را مشخص کن

از lang=fa و dir=rtl در عنصر HTML استفاده کن تا متن و چیدمان از ابتدا مناسب زبان فارسی باشد.

منطق چیدمان را مستقل از راست و چپ کن

ویژگی‌های منطقی CSS مانند margin-inline و padding-inline تغییر جهت را ساده‌تر می‌کنند.

کیبورد بخش جدایی‌ناپذیر UX است

کاربر باید بتواند بدون موس به بخش اصلی برود، منو را باز کند، جست‌وجو را استفاده کند و پنجره‌ها را ببندد.

به فونت و خوانایی توجه کن

فونت محلی، ارتفاع خط مناسب، طول متعادل پاراگراف و رنگ با کنتراست کافی، تجربه خواندن مقاله را بهتر می‌کنند.

نکته پایانی

ساده شروع کن، با ابزار مرورگر اندازه بگیر و فقط همان بخش‌هایی را پیچیده کن که واقعاً به آن نیاز دارند.
