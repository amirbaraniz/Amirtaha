زمانی که یک سایت به فریم‌ورک نیاز ندارد و APIهای مرورگر کافی هستند. در ادامه چند اصل برای بهتر شدن تجربه کاربر را مرور می‌کنیم.

همه پروژه‌ها به فریم‌ورک نیاز ندارند

برای یک رزومه شخصی، تعاملات اصلی محدود به ناوبری، جست‌وجو، فیلتر و چند دکمه هستند. Vanilla JavaScript برای بسیاری از این نیازها کافی است.

استفاده از قابلیت‌های داخلی مرورگر

IntersectionObserver، Web Share API، dialog و lazy loading بومی می‌توانند نیاز به کتابخانه اضافی را کاهش دهند.

DOM را با دقت تغییر بده

برای محتوای نامطمئن از textContent استفاده کن. تغییرات DOM را گروهی انجام بده و از محاسبات سنگین در رویداد Scroll خودداری کن.

پیشرفت تدریجی

ابتدا صفحه را با HTML کاربردی بساز؛ سپس JavaScript امکانات اختیاری را به آن اضافه کند. این روش در شرایط خطا نیز تجربه بهتری می‌سازد.

نکته پایانی

ساده شروع کن، با ابزار مرورگر اندازه بگیر و فقط همان بخش‌هایی را پیچیده کن که واقعاً به آن نیاز دارند.
